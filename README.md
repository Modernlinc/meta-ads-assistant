# 摩登领客 · Meta 广告助手

面向 macOS 上的 Codex 项目。用已有品牌、商品和市场资料准备一条 Meta 广告，读取已授权的广告账户，并沿同一个 Ad 做日常复盘。

## 快速开始

1. [下载 A3 客户使用包](https://github.com/Modernlinc/meta-ads-assistant/releases/download/v1.4.2-a3/modernlinc-meta-ads-customer-v1.4.2-a3.zip)，解压后打开《先读我_客户使用手册.html》或 PDF。
2. 以 macOS 和 Python 3.12 或更新版在自己的 Codex 项目安装 Skill。安装版为 `0.1.0.dev1+v142a3`。
3. 在该项目使用 `$codex-ads-live`。按手册接通自己的 Meta App 和具名账户，将品牌档案和商品图放进项目，再生成首投草案或查看已有数据。

账户接通按实际具名只读回执核对。上传素材、建单和启用由相应负责人分别批准。受控自动执行需要管理员完成本机部署。
