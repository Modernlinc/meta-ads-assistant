# 订阅回款情景与预算约束

MC-COM-03 · 2026-11-27.1

作者或归属 启发：Zach Stuck（MarsMen）在 Scalability School 的经营讨论；模型为 MODERNLINC 设计。来源 YT-o9jxZGLm3Qs，见 [来源登记](../sources.json)。

## 原问题

订阅业务的预计复购收入与实际现金回收日不同；订阅周期、折扣和取消会使按总 MRR 放预算失真。

## 执行步骤

- 固定收入确认与现金到款定义。
- 分周期/首单优惠 cohort 估计保留与回款。
- 回测历史预测并呈现误差。
- 计算基线/压力情景下逐日现金。
- 把现金可承受的支出范围交到人工预算审批。

## 指标与计算

```json
[
  {
    "name": "预计回款",
    "formula": "Σ(在日期 t 应扣款金额 × 持续订阅概率 × 扣款成功概率) − 预计退款",
    "limits": "简化设计；须处理税、换汇与结算延迟，非已验证预测器。"
  },
  {
    "name": "预计期末现金",
    "formula": "期初现金 + 本期实际/预计到款 − 已承诺支出 − 拟议广告支出",
    "limits": "不把会计收入或 MRR 等同到款。"
  },
  {
    "name": "预测误差",
    "formula": "实际回款 − 同版本预测回款",
    "limits": "保留预测版本与发生日，不能用事后重估覆盖旧误差。"
  }
]
```

## 前提假设

- 订阅数据可合法授权读取；使用期间的 offer 与 cohort 漂移可追踪。

## 适用情况

- 已有稳定订阅历史且能对齐账单、现金和成本的业务。

## 不适用情况

- 一次性购买为主、无订阅账期或无足够历史的商店。

## 风险

- 取消与折扣的选择偏差、扣款失败、提前备货、复购延迟、对单客过拟合。

## 反例

- 合同显示月度收入相同，改为季度配送后本月回款仍可能骤降。
- 预测准确但货款提前支付时仍需现金限制。
