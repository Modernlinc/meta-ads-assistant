# IA 优化设置的受控比较

MC-MEA-03 · 2026-11-27.1

作者或归属 启发：CTC / Tony Chopp / McCay Rasmussen；证据限制与流程为 MODERNLINC 设计。来源 YT-aR1yByVO3ac，见 [来源登记](../sources.json)。

## 原问题

新的优化设置出现早期正向结果时，需要区分优化效果、平台报告与独立经营增量。

}

## 执行步骤

- 明确测试问题是优化还是测量。
- 锁定两组共同结果及其他变量。
- 预设试验与停止规则。
- 分别呈现原数、增幅分母和不确定性。
- 设计独立经营复核，再决定是否逐步扩展。

## 指标与计算

```json
[
  {
    "name": "以对照为基数的相对变化",
    "formula": "(处理组结果 − 对照组结果) / 对照组结果",
    "limits": "原数精度、对照定义需明确；不替换来源含糊的 lift 字段。"
  },
  {
    "name": "每单位支出结果",
    "formula": "相同结果定义 / 对应试验组支出",
    "limits": "只有两组分母可比才比较；归因窗口不同的报表值不天然同义。"
  }
]
```

## 前提假设

- 试验设置确实可用且有可比较分配；其他因素控制并不消除所有测量偏差。

## 适用情况

- 有实验能力且希望验证不同优化设置的广告账户。

## 不适用情况

- 把一个匿名账户早期结果直接用于全账户或跨客户部署。

## 风险

- 平台自报偏差、赢家早停、两组学习状态差异、未披露分配、净收入与转换价值混淆。

## 反例

- 初试正面，扩展到其他 SKU、预算或季节后可能不成立；参见独立保存的回退案例。
