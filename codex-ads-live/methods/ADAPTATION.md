# 用一句话开始 Meta 广告工作

在 Codex 打开已经安装好 Skill 的项目，直接说明要办的事。首次接入真实平台数据时，由账户本人完成 [Meta 接入](../references/CUSTOMER_SOP.md)。尚未授权时，也能用已有商品资料和本地导出做草案或复盘。

| 可以直接说 | 有帮助的资料 | 可以得到的结果 |
| --- | --- | --- |
| 帮我设计一轮新素材测试 | 商品、候选素材、可用预算、主转化事件 | 测试变量、预算和样本充分性、停止条件 |
| 这个账户应该用 CBO 还是 ABO | 目标、预算、账户历史、素材量 | 适用条件、取舍和草案结构 |
| 看看实拍素材，给我两套可比较的文案 | 实际素材、商品事实、允许使用的渠道 | 有依据的原创文案、已观察及缺项 |
| 研究这些竞品广告并找出自己的创意方向 | 公共广告链接或获准导出的记录、自己的品牌事实 | 区分观察和推断的创意方向 |
| 为什么 CPM 上升但订单没增加 | 同口径的前后报表及事件说明 | 分段诊断、可能解释及下一项核查 |
| 检查 Pixel/CAPI 是否重复记单 | 脱敏事件样本、数据集、落地页和 UTM | 样本配对、重复与缺项、回读指引 |
| 帮我核对 Shopify 退款与广告花费 | 订单、退款、广告消耗导出和核算日期 | 统一口径的对账报告及工作簿 |

助手会自动选择和核对本地方法，必要时获取经校验的固定版本文本。四项核心方法可离线使用。网络暂不可用时，助手先用本地资料继续，并说明影响结论的缺口。不同策略会按目标、样本、预算和当前证据比较。客户日常只需要提供品牌材料或需要核对的业务事实。

店铺核算由本工具实际计算，随包的方法正文提供口径和分析原则。创建、启用和调整广告仍沿同一账户和计划完成原有的确认步骤。测试、预览和真实投递分别有各自结果。广告以外的平台和原生桌面验收边界见[安装及运行说明](../references/INSTALL_RUN.md)。
