# MODERNLINC · Meta 广告账户助手

安装成功后，在当前 Codex 项目说出业务目标。助手负责方法选择与装载，并把结果交给实际业务模块。[客户开箱方法](methods/ADAPTATION.md)

本候选已在 macOS 验证项目安装和 CLI。Windows 提供 PowerShell 安装和凭据管理器步骤，Windows 实机、Codex 桌面和凭据管理器的原生验收待完成（`NOT_RUN_NO_WINDOWS_HOST`）。本轮实机验收已获用户豁免（`PASS_BY_USER_WAIVER`）。

初次配置保存在客户工作区。后续可沿原账户准备广告、读取报告和核对原操作。

1. 按[使用说明](references/INSTALL_RUN.md)检查环境，将 Skill 安装到自己的项目。
2. 按[账户接通流程](references/CUSTOMER_SOP.md)办理所需权限，选择本人临时输入或本机系统凭据引用，读取一次指定账户。Windows 见[安装与凭据说明](references/WINDOWS_CLIENT.md)。
3. 将返回的账户编号与广告管理工具里的编号核对。后续打开同一项目即可接续。
4. 准备投放时阅读[首投操作](references/FIRST_LAUNCH_CUSTOMER.md)。需要保存品牌资料、审阅素材、安排逐项操作或复盘时，打开[品牌、素材与复盘指南](references/CREATIVE_AND_DELIVERY.md)。配置 macOS 受管执行的管理员请阅读[部署说明](references/FIRST_LAUNCH_LOCAL_AUTHORITY.md)。
