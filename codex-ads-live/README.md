# MODERNLINC · Meta 广告账户助手

在自己的 Mac 和 Codex 项目中接通指定的 Meta 广告账户。初次配置保存在客户工作区，之后可继续使用同一账户准备广告、读取报告和核对原操作。

1. 按[使用说明](references/INSTALL_RUN.md)检查环境，将 Skill 安装到自己的项目。
2. 按[账户接通流程](references/CUSTOMER_SOP.md)办理所需权限，在本机保存凭据，读取一次指定账户。
3. 将返回的账户编号与广告管理工具里的编号核对。后续打开同一项目即可接续。
4. 准备投放时再阅读[首投操作](references/FIRST_LAUNCH_CUSTOMER.md)。需要自动建单和受控启用的管理员请阅读[部署说明](references/FIRST_LAUNCH_LOCAL_AUTHORITY.md)。
